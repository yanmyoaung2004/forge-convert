## Phase A — PDF merge + compress (core → pdf → CLI → desktop)

- Core `ports.rs`: `PdfMerger { merge(pdf_list: &[&[u8]]) -> Result<Vec<u8>> }`,
  `PdfCompressor { compress(pdf_bytes, level: PdfCompressLevel) -> Result<Vec<u8>> }`
  (`level`: Light { prune only } / Balanced { prune + recompress streams }).
  Re-export in `forge-core/src/lib.rs`.
- `forge-pdf`: `LopdfMerger` (load each → concatenate pages into one Document via
  printpdf `append_document` on re-serialized docs; empty list = InvalidConfiguration),
  `LopdfCompressor` (Light: `prune_objects` + `save_to`; Balanced: + `compress()`).
  ≥4 tests: merge 2 PDFs page count adds, merge rejects empty/garbage, compress
  shrinks-or-equal, compress round-trips as valid PDF.
- CLI: `pdf-merge a.pdf b.pdf... --output merged.pdf [--on-collision]`,
  `pdf-compress in.pdf [--level light|balanced] [--output out.pdf]`.
  History ops `"pdf-merge"`, `"pdf-compress"`. Exit codes unchanged.
- Desktop: `merge_pdfs {inputs[], output?}`, `compress_pdf {input, level?, output?}`
  commands + PDF tab buttons (two new rows reusing `pickFiles` + result reveal).
- **Commit:** `feat(pdf): merge + compress - LopdfMerger/Compressor, CLI, desktop PDF tab`

## Phase B — Favicon / app-icon generator (image → CLI → desktop)

- `forge-image`: `generate_icons(canonical, sizes) -> Vec<(u32, Vec<u8>)>` —
  resize via existing `resize_canonical` (Lanczos3), encode PNG per size;
  ICO via `image::codecs::ico::IcoEncoder` (needs `ico` feature on `image 0.25`
  workspace dep). Sizes: 16/32/48 (ICO frames) + 180/192/512 PNG files.
  Returns `(size, png_bytes)` list; CLI/desktop write files.
- CLI: `favicon in.png --output-dir ./icons [--sizes 16,32,48,180,192,512]`
  writes `favicon.ico` (16+32+48 frames) + `icon-180.png` etc + prints
  `<link rel="icon">` snippet to stdout (copy-paste ready).
- Desktop: Convert tab "Favicon" section OR PDF-tab-style row: pick image →
  generate → reveal folder + snippet in result card.
- Tests: 16px ICO magic (`00 00 01 00`), PNG magic per size, dims exact.
- **Commit:** `feat(icons): favicon generator - multi-size PNG + ICO, CLI snippet, desktop`

## Non-goals (v0.5.0 candidates)

- PDF renderer (`hayro` spike), Mermaid→blocks, diagram PNG export,
  OCR for scanned PDFs, `.doc` legacy output, cloud anything.

## Risks (facts)

- `qrcode 0.14` API shape: verify against vendored sources after `cargo add`
  (not from memory) — render-to-image path differs per version.
- `image` `ico` feature: check it doesn't pull extra native deps (pure-Rust expected).
- `append_document` works on printpdf docs, NOT raw lopdf docs — merge must
  round-trip via printpdf or manipulate lopdf page trees directly; spike in code,
  test proves it.
- `SubtleCrypto` needs secure context: Tauri `tauri://` qualifies; plain
  `vite dev` may not — QR/hash-file Rust path covers files regardless.
